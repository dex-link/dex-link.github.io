DexLink: Synthesizing Dexterous Demonstrations from Chained Hand–Object Poses

DexLink synthesizes diverse dexterous behaviors from sparse, reusable hand–object interaction templates. Given key task waypoints, it retargets static interaction templates to target objects, links the retargeted poses into an approximate reference trajectory, and uses residual reinforcement learning to refine the reference into a closed-loop policy.

  • Simulation provides a scalable platform for generating dexterous manipulation data, but which tasks and behaviors to generate remains an open challenge.

Existing Behavior Specifications

  • Indirect specifications—task-specific rewards, hand priors, or wrist-only targets—are reusable, but provide weak control over the learned hand–object interactions.
  • Dense specifications—demonstrations or dense motion references—provide detailed guidance, but are costly to collect and typically tied to a specific task–object pair.
  • This motivates a middle-ground task representation that achieves the best of both worlds: explicit interaction guidance with less task- and object-specific data.

DexLink

  • We use hand–object interaction templates: a template captures how a hand interacts with an object or object part.
    • It can specify the intended grasp, contact region, and hand orientation.
    • Templates can be reused across object instances and even across related object categories.

Task Specification and Object-Aware Retargeting

Object-state waypoints specify the desired task progression. Interaction templates are assigned independently at selected waypoints and retargeted to the robot hand and target object.

Reference Trajectory Construction

The retargeted robot hand transforms are interpolated along the object-state waypoints to construct an approximate kinematic reference.

Residual RL Refinement

A residual policy refines the approximate reference into a physically grounded closed-loop trajectory.
